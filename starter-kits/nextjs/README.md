This is a [Subframe](https://subframe.com) Next.js Starter Kit that provides just enough configuration to get up and running with Subframe.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then run the project:

```bash
npm run dev
```

## Adding Subframe components

Run `npx @subframe/cli sync` in this project to pull the components and theme from your Subframe project into `src/ui`.
