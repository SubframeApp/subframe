## Import alias

Set the path prefix used for component imports in generated code.

**Default:** `@/ui/components`

This determines how import statements appear in your exported code:

```tsx
import { Button } from "@/ui/components/Button"
```

Change this to match your project's directory structure and TypeScript path aliases.

## Company context

Add company and product context in **Docs** under **Design System**. Use the document labeled **Always read by the agent** for your product description, audience, tone, and design guidelines. See [Personalizing AI](/design/ask-ai/personalizing-ai).

## Icon imports

Choose how icons are imported in generated code.

#### Import as component

Icons are imported as React components and passed as elements:

```tsx
import { FeatherCheck } from "@subframe/core"
```

```tsx
<Button icon={<FeatherCheck />} />
```

#### Import as string

For legacy projects. Icons are referenced by name as strings:

```tsx
import * as SubframeCore from "@subframe/core"
```

```tsx
<SubframeCore.Icon name="FeatherCheck" />
```

<Info>
  If your project has uploaded custom icons, you must use "Import as component". The string option is disabled when
  custom icons are present.
</Info>
