## Opening code export settings

1. Open your project
2. Find **Project** in the left sidebar
3. Click the gear icon labeled **Configure code export**
4. Change the settings below, then click **Save**

## Setting the import alias

The **Import alias** is the path prefix for your generated UI files. The default is `@/ui`, which produces component imports such as:

```tsx
import { Button } from "@/ui/components/Button"
```

Subframe adds `/components`, `/layouts`, or `/icons` as needed. Match the prefix to the aliases configured in your codebase. The CLI stores its local alias and sync directory in `.subframe/sync.json`; see [manual installation](/develop/frameworks/manual).

## Choosing icon imports

**Import as component** exports icons as React components:

```tsx
import { FeatherCheck } from "@subframe/core"

;<FeatherCheck />
```

**Import as string** uses names with `SubframeCore.Icon` for legacy projects:

```tsx
import * as SubframeCore from "@subframe/core"

;<SubframeCore.Icon name="FeatherCheck" />
```

Projects with uploaded icons must use **Import as component**.
