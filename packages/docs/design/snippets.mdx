Use snippets for patterns such as navigation bars, page headers, and groups of cards. Inserting a snippet copies its elements into the design.

<Frame>
  <img src="/images/snippets/insert-menu.png" alt="Snippet insert menu" />
</Frame>

Unlike components, changes to snippets will not affect anywhere that uses them.

## Creating a snippet

1. Right-click or press <kbd>/</kbd> to open [quick actions](/design/design-mode/quick-actions)
2. Select **Save as snippet**
3. Preview your snippet and give it a name
4. Click **Create**

## Inserting snippets

There are two ways to insert snippets:

- Open the **Insert** <Icon icon="plus" size={16} /> panel from the toolbar at the bottom of the canvas and select **Snippets**
- Search for the snippet using the [quick insert](/design/design-mode/adding-elements) <Icon icon="plus" size={16} /> menu

See [adding elements](/design/design-mode/adding-elements) for more info.

## Managing snippets

Open **Snippets** in the left sidebar. You can edit or delete snippets from here.

Use the sort control at the top of the list to order snippets by **A-Z** (default), **Recently edited**, or **Recently created**.
