Canvases group related pages together. The pages on a canvas are used to create [prototypes](/design/prototype-mode/overview).

## Creating a canvas

1. Open the **Pages** section in the left sidebar
2. Click **New canvas** at the bottom of the left sidebar

## Renaming a canvas

Double-click a canvas name in the pages sidebar to rename it. Press <kbd>Enter</kbd> to confirm or <kbd>Esc</kbd> to cancel.

## Adding pages to a canvas

1. Click <Icon icon="ellipsis" size={16} /> on a page
2. Select **Move to canvas** > select the canvas (or **New canvas...**)

You can also drag pages directly onto a canvas from the pages list when editing a page.

To start a new page from an element, drag it from the [Insert panel](/design/design-mode/adding-elements#method-2-drag-and-drop-from-the-insert-panel) to an empty spot on the canvas, or pick up an [insert tool](/design/design-mode/adding-elements#method-3-insert-tools) and click an empty spot. An empty canvas shows an <Icon icon="plus" size={16} /> **Add page** button in the middle.

## Arranging pages on the canvas

Pages sit anywhere on the canvas, and you place them where you like:

- Drag a page by its name in the header to move it. Hold <kbd>Shift</kbd> while dragging to move it only horizontally or vertically.
- Hold <kbd>Option</kbd> while dragging a page to duplicate it
- Drag across an empty area of the canvas to select every page the box touches. Hold <kbd>Shift</kbd> to add to the current selection.
- <kbd>Shift</kbd> + click page headers to select multiple pages, then drag any of them to move them together

While you drag, guides appear when a page's edges or center line up with another page.

### Aligning pages

Select two or more pages, then click an alignment button in the Inspector panel, or press a shortcut:

| Alignment                | Mac                                 | Windows and Linux                |
| ------------------------ | ----------------------------------- | -------------------------------- |
| Align left               | <kbd>Option</kbd> + <kbd>A</kbd>    | <kbd>Alt</kbd> + <kbd>A</kbd>    |
| Align horizontal centers | <kbd>Option</kbd> + <kbd>H</kbd>    | <kbd>Alt</kbd> + <kbd>H</kbd>    |
| Align right              | <kbd>Option</kbd> + <kbd>D</kbd>    | <kbd>Alt</kbd> + <kbd>D</kbd>    |
| Align top                | <kbd>Option</kbd> + <kbd>W</kbd>    | <kbd>Alt</kbd> + <kbd>W</kbd>    |
| Align vertical centers   | <kbd>Option</kbd> + <kbd>V</kbd>    | <kbd>Alt</kbd> + <kbd>V</kbd>    |
| Align bottom             | <kbd>Option</kbd> + <kbd>S</kbd>    | <kbd>Alt</kbd> + <kbd>S</kbd>    |

## Editing pages on the canvas

You can edit pages directly on the canvas without opening them:

- Click an element on any page to select it, then edit its properties in the Inspector panel
- Drag an element from one page to another to move it between pages
- Drag an element to an empty spot on the canvas to turn it into a new page. Hold <kbd>Option</kbd> while dropping to copy it instead.
- Use the **Layers** section in the left panel to view and navigate each page's element hierarchy

To open a page in its dedicated editor, hover its header and click <Icon icon="maximize-2" size={16} /> **Open in page editor**, or right-click the page and select **Open in page editor**.

## Duplicating a canvas

1. Click <Icon icon="ellipsis" size={16} /> on a canvas in the pages sidebar
2. Select **Duplicate canvas**

Duplicating a canvas copies all of its pages along with the canvas's [prototype](/design/prototype-mode/overview).

## Deleting a canvas

1. Click <Icon icon="ellipsis" size={16} /> on a canvas in the pages sidebar
2. Select **Delete canvas...**
3. Confirm in the dialog

Deleting a canvas also deletes every page on it. To keep those pages, move them to another canvas with **Move to canvas** before deleting.

<Warning>Deleting a canvas can only be undone using project-level version history</Warning>
