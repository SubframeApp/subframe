Keep reusable guidance in your project's **Docs**, and reference specific designs in your prompts.

## Adding project guidance

1. Open **Docs** in the left sidebar
2. Click **New doc**
3. Give the document a title and write your guidance. Changes save automatically

Describe your product, audience, terminology, and design rules. Use concrete examples: “Use sentence case for buttons” or “Use a destructive button only for actions that delete data.”

The agent can read project docs as context. Type <kbd>@</kbd> in a prompt to reference a document when its guidance matters to a particular task.

## Referencing existing designs

Your components and theme give the agent reusable building blocks. Add [references with @](/design/ask-ai/adding-context) to show which pages, components, or snippets it should follow.

For example: “Create a billing page using @Settings page for the layout and @Plan card for the pricing options.” Explain which parts of each reference to preserve and what should change.
