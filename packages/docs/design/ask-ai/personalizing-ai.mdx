Use project Docs to describe your product, audience, and design guidelines. The agent reads this context alongside your design system when working on designs.

## Project context

1. Open **Docs** under **Design System**
2. Open the document labeled **Always read by the agent**
3. Describe your product, audience, tone, and design guidelines. Changes save automatically.

Use **New** to add more documents for specific features or patterns. The agent can read these as needed, and you can reference them explicitly with [@](/design/ask-ai/adding-context).

## Referencing existing designs

Give the agent references to guide its work:

- **Design system**: Your components and theme provide reusable building blocks and tokens
- **Pages**: Reference a page with **@** when you want the agent to follow its layout or style
- **Snippets**: Reference reusable compositions such as headers and navigation bars
