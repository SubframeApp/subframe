---
title: Image to design
description: Upload images to prompt AI when generating designs.
---

Upload screenshots or mockups and the agent recreates designs using your components and theme.

## Upload images

1. Click the **image icon** in the agent chat toolbar or drag images directly into the prompt area.
2. Attach as many images as you need — each appears as a thumbnail you can remove before sending.
3. Add a prompt describing how to use them
4. Press <kbd>Enter</kbd> to generate

The agent uses the images as references and creates editable designs with your components and theme. Ask for variations if you want to compare directions.

Supported formats: PNG, JPG, JPEG, WebP

## Import from Figma

1. In Figma, select a frame to copy as PNG (right-click or press <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>)
2. In agent chat, paste the image into the prompt area
3. Add a prompt and press <kbd>Enter</kbd>

## Reference a web page

Paste a URL into the prompt and the agent captures a screenshot and the page's content to use as a reference — matching the layout and pulling in exact copy.

1. Paste a URL into the agent chat prompt
2. Add a prompt describing what to build from it
3. Press <kbd>Enter</kbd>

<Note>
  The agent only fetches URLs you paste in. To reference another page inside your own project, use [<kbd>@</kbd>{" "}
  mentions](/design/ask-ai/adding-context) instead.
</Note>
