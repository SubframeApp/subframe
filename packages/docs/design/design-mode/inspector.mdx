The Inspector panel shows all editable properties for the selected element. Select any element on the canvas to see its properties in the right sidebar.

## Editing overrides

Overrides let you customize properties for specific contexts without changing the base element. Use overrides for:

- **[Responsive overrides](/design/design-mode/responsive-design)** — breakpoint overrides for properties that need different values at specific screen sizes
- **[Variant overrides](/design/components/variants)** — styles applied when a component's Boolean or Enum option is active
- **[State overrides](/design/components/states)** — styles for hover, active, or focus states

<Frame>
  <img src="/images/design-mode/overrides.png" alt="Inspector panel showing the element properties" />
</Frame>

When a property has an override, a pink dot appears next to it. Click the pink dot and select **Reset override** to remove it. For breakpoint overrides, the menu names the breakpoint and also offers **Apply to all breakpoints**.

## Prebuilt interactive components

The inspector lets you set the default state for some prebuilt components, so you can preview how they look in different conditions:

- **Checkbox**, **Switch**, **Radio Group item**, **Toggle Group item** — toggle the **Checked** prop
- **Text Field**, **Text Area** — type into the **Value** prop

These controls only affect how the instance renders in design mode and preview. Runtime state in generated code is controlled by your application — see [headless components](/develop/concepts/code-generation#headless-components).

## Keyboard shortcuts

Most properties in the inspector have a keyboard shortcut. Hover over any edit action to see its shortcut.
