## Applying tokens

Background, color, text, border, corner, and shadow properties can use a [theme token](/design/theme/customizing-theme) or a custom value.

- Click <Icon icon="plus" size={16} /> to add a custom value.
- Click the token icon in the section header (**Apply token**, **Apply text style**, or **Apply border style**) and pick a token. On an empty section, hover the row to show it.

To turn an applied token into a custom value, hover the token and click **Detach**.

## Setting sizes

Set **W** and **H** by typing a value, dragging the slider, or opening the value menu, where you can also pick **Hug** or **Fill**. To limit how far an element can shrink or grow, click **...** in the **Size** header and select **Add min width**, **Add max width**, **Add min height**, or **Add max height**. Each limit gets its own row under its axis.

## Overrides properties

Overrides let you customize properties for specific contexts without changing the base element. There are two types of overrides:

- **[Responsive overrides](/design/design-mode/responsive-design)** — breakpoint overrides for properties that need different values at specific screen sizes
- **[Variant overrides](/design/components/variants)** — different values for component instances

When a property has an override, a pink dot appears next to it. Click the pink dot to remove the override and revert to the default value.

## Prebuilt interactive components

The inspector lets you set the default state for some prebuilt components, so you can preview how they look in different conditions:

- **Checkbox**, **Switch**, **Radio Group item**, **Toggle Group item** — toggle the **Checked** prop
- **Text Field**, **Text Area** — type into the **Value** prop

These controls only affect how the instance renders in design mode and preview. Runtime state in generated code is controlled by your application — see [headless components](/develop/concepts/code-generation#headless-components).

## Keyboard shortcuts

Most properties in the inspector have a keyboard shortcut. Hover over any edit action to see its shortcut.
