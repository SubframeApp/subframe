## Searching your project

Press <kbd>Cmd</kbd> + <kbd>K</kbd> to search your project. You can also select **Search project...** in the project menu.

- Create a canvas, page, component, snippet, or doc
- Jump to a canvas, page, component, snippet, or doc
- Open a project section, such as **Theme** or **Icons**, or a settings page such as **Billing**

## Step back to where you came from

Press <kbd>Esc</kbd> twice to navigate back up your editing history:

- From a component or snippet that you opened from another design, return to that previous design
- From a page on a canvas, return to the canvas

In the page editor, the canvas pulses on the first press as visual feedback.
