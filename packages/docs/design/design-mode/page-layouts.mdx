Page layouts are reusable templates that wrap your page content with headers, sidebars, modals, or drawers.

<Frame>
  <img src="/images/design-mode/page-layouts.png" className="w-[304px]" alt="The Page Layout section of the Inspector with the Blank layout selected and a + button for a new layout" />
</Frame>

Blank projects start without prebuilt layouts. [Create a layout](#creating-a-new-layout) to add one.

All layouts have a slot property called `children` that cannot be deleted. Any page contents will be rendered inside this slot.

## Applying a layout

1. Open a page in the page editor. On the canvas, hover the page's name and click **Open in page editor**.
2. Ensure you don't have any elements selected. You should see layouts in the right sidebar.
3. Click on the layout to apply it to the page.

## Creating a new layout

<Frame>
  <img src="/images/design-mode/new-layout-dialog.png" alt="The New layout dialog with a Layout name field, the Blank layout option selected, and a preview of the layout on the right" />
</Frame>

1. Open a page in the page editor.
2. Ensure you don't have any elements selected. You should see layouts in the right sidebar.
3. Click **+** next to **Page Layout**.
4. Name the layout, then pick a layout template or start from a blank layout.
5. Click **Create layout**.
