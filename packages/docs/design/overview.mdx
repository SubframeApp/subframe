- **Left sidebar:** open pages and canvases, browse your theme and component library, and select elements in **Layers**.
- **Canvas:** select and edit elements, arrange pages, and try different screen sizes.
- **Inspector panel:** change the selected element's layout, styles, content, and component properties.

The toolbar at the bottom of the canvas includes selection, insertion, comments, and preview. Press <kbd>V</kbd> to return to the selection tool, or use **Insert** <Icon icon="plus" size={16} /> to browse elements, components, and snippets.

## Switching between design and code

Use the tabs at the top of the Inspector panel:

- **Design:** edit element properties visually.
- **Code:** inspect and [export the generated code](/design/code-mode/overview).

When you open a canvas in the web app, you can also use **Prototype** to [generate an interactive prototype](/design/prototype-mode/overview). This tab is not shown in the desktop app's mode switcher.

Open [Agent chat](/agent/overview) with **Agent** or <kbd>Cmd</kbd> + <kbd>/</kbd> to create or edit designs from a prompt.

## Showing and hiding panels

Press <kbd>Cmd</kbd> + <kbd>\\</kbd> to cycle through panel layouts: both panels visible, left panel collapsed, then both panels hidden. Press <kbd>Cmd</kbd> + <kbd>.</kbd> to show or hide all panels, including Agent chat.

On the web, the panel icon beside **Agent** shows or hides the Inspector.

## Designing across screen sizes

Use **Breakpoint** in the Inspector to switch between the base design and smaller screen sizes. Base styles apply at every width; narrower breakpoints override only the properties you change.

Start with the base design, then add [responsive overrides](/design/design-mode/responsive-design) where needed.

## Collaborating on designs

Team members can edit together. Avatars at the top of the Inspector show who is viewing the design. Use **Share** to [invite teammates or publish a public preview](/design/design-mode/share-designs).
