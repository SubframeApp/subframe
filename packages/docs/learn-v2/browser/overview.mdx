Use the browser to work with your running app next to your designs and agent.

{/* TODO: Add screenshot of a browser tab with a local app open */}

Each browser tab has three modes:

- **Preview**: interact with the page like in any browser
- **Inspect**: select elements to edit them or copy them as designs
- **Annotate**: add implementation notes or images for your agent

Click **Capture** to copy the full page as an editable design.

To get started, see [Previewing your local app](/learn-v2/browser/previewing-your-local-app).
