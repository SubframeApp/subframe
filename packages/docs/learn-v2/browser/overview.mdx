The built-in browser is a browser for building software. Open your running app next to your canvas and agent, then work directly on the live page.

{/* TODO: Add screenshot of a browser tab with a local app open */}

Each browser tab has three modes:

- **Preview**: interact with the page like in any browser
- **Inspect**: select elements to see their source, edit them, and send changes to your agent
- **Annotate**: comment on elements to give feedback or agent context

From any page, use **Capture** to import what you see onto the canvas as an editable design.

To get started, see [Previewing your local app](/learn-v2/browser/previewing-your-local-app).
