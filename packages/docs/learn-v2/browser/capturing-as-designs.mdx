To get started, [open your app or website in a browser tab](/learn-v2/browser/previewing-your-local-app).

## Capturing a page

1. Click **Capture** in the browser toolbar
2. Add the page to a flow:
   - Click **Add to flow** in the confirmation message, then select a flow
   - Or open a flow and press <kbd>Cmd</kbd> + <kbd>V</kbd> to paste it

## Capturing an element

Capture an element when you only need part of the page.

1. Click **Inspect** in the browser toolbar
2. Click on an element
3. Press <kbd>Cmd</kbd> + <kbd>C</kbd> or click **Copy selection** in the Inspector panel
4. Paste the element into a flow or agent chat
