---
title: Troubleshooting
description: Fix common issues with the built-in browser.
---

Most browser problems come down to one of three causes: the dev server, an outdated app, or the page itself.

<AccordionGroup>
  <Accordion title="My dev server doesn't show up under Detected servers">
    Make sure the server is running. Subframe detects servers whose working directory is inside a Git checkout or whose process is a known development runtime. If yours doesn't qualify, open it directly by entering its URL.
  </Accordion>
  <Accordion title="A feature is missing or disabled">
    Your desktop app may be out of date. Subframe checks for updates at launch and every few hours, but installing requires a restart. Quit and reopen Subframe to apply a downloaded update.
  </Accordion>
  <Accordion title="My app doesn't render or inspect correctly">
    The browser and canvas work with applications that render on the web. If a page misbehaves, try reloading the tab. If inspecting still fails, reach out in our [Slack Community](https://join.slack.com/t/subframecommunity/shared_invite/zt-380uma6dv-_lr7_bDLU5DJcoygfUYkeQ).
  </Accordion>
</AccordionGroup>
