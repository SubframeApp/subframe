---
title: Troubleshooting
description: Fix common issues with the built-in browser.
---

<AccordionGroup>
  <Accordion title="My dev server doesn't show up under Detected servers">
    Make sure the server is running. If **Show all** appears, click it. If your server still doesn't appear, enter its localhost URL in the address bar.
  </Accordion>
  <Accordion title="A feature is missing or disabled">
    Browser editing is disabled in version history and for viewers. If a control is missing, quit and reopen the desktop app to install the latest update.
  </Accordion>
  <Accordion title="My app doesn't render or inspect correctly">
    Reload the tab. If the problem continues, reach out in our [Slack Community](https://join.slack.com/t/subframecommunity/shared_invite/zt-380uma6dv-_lr7_bDLU5DJcoygfUYkeQ).
  </Accordion>
</AccordionGroup>
