Subframe is a design tool for your codebase. It brings the three tools you use to make software together in one place:

- **[Canvas](/learn-v2/design/overview)**: design on an infinite canvas using HTML, CSS, React, and Tailwind
- **[Browser](/learn-v2/browser/overview)**: preview your live app, edit it visually, and capture it as a design
- **[Agent](/learn-v2/agent/overview)**: work with Claude Code, Codex, or Subframe AI credits across your designs, browser, and code

<Note>
  Use the [desktop app](/learn-v2/desktop-app) to work with your local codebase, development server, and coding agent.
  Download it for macOS at [subframe.com/downloads ↗](https://subframe.com/downloads).
</Note>

## How Subframe works

Subframe lets you go from design to code and back. Here's a typical workflow:

<Steps>
  <Step title="Open your app">
    [Open your local app](/learn-v2/browser/previewing-your-local-app) in the built-in browser.
  </Step>
  <Step title="Edit it live">
    [Use **Inspect**](/learn-v2/browser/making-live-edits) to change the running page visually.
  </Step>
  <Step title="Design on the canvas">
    [Capture the page or an element](/learn-v2/browser/capturing-as-designs) as an editable design and explore bigger changes on the canvas.
  </Step>
  <Step title="Ship with the agent">
    [Ask the agent to implement your design](/learn-v2/agent/making-code-changes) in your connected codebase.
  </Step>
</Steps>

Ready to try it? Start with the [Quickstart](/learn-v2/quickstart).
