Subframe is a design tool for your codebase. It brings the three tools you use to make software together in one place:

- **Canvas**: an infinite design canvas where the material is HTML & CSS, with full support for React and Tailwind
- **Browser**: preview your live app, edit it visually, and bring anything onto the canvas
- **Agent**: work with Claude Code or Codex across your designs, browser, and code

<Note>Subframe is a macOS app. Download it at [subframe.com/downloads ↗](https://subframe.com/downloads).</Note>

## How Subframe works

Subframe lets you easily go from design to code and back. Here's a typical workflow in Subframe:

<Steps>
  <Step title="Open your app">
    Connect your codebase and open your running app in the built-in browser.
  </Step>
  <Step title="Edit it live">
    Inspect turns the page into an editable design. Make the 1px change yourself instead of prompting for it.
  </Step>
  <Step title="Design on the canvas">
    Copy any element (or capture entire flows) onto the canvas and explore like you would in any design tool.
  </Step>
  <Step title="Ship with the agent">
    Paste a design into chat as context, and the agent implements it in your codebase.
  </Step>
</Steps>
