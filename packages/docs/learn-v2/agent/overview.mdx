Agent chat works in the same workspace as your designs, running app, and codebase. [Use Subframe AI credits or connect Claude Code or Codex](/learn-v2/agent/connecting-an-agent) to get started.

## Working across designs, browser, and code

Use the agent to:

- [Create or edit designs](/learn-v2/design/ask-ai/prompt-to-design) in Subframe
- Turn [browser edits and comments](/learn-v2/browser/making-live-edits) into code changes
- [Implement a design](/learn-v2/agent/making-code-changes) in your connected codebase
- [Start your local development server](/learn-v2/browser/previewing-your-local-app)

The agent automatically receives context from the view you're working in. You can also [add more context](/learn-v2/agent/giving-your-agent-context) by referencing project content, pasting designs, or attaching images.

To make changes to local code, first [connect your codebase](/learn-v2/agent/connecting-your-codebase).

## Opening Agent chat

In the [desktop app](/learn-v2/desktop-app), click **Agent** in the title bar or press <kbd>Cmd</kbd> + <kbd>/</kbd>.

Agent chat stays open as you move between designs and browser tabs. Your [chats can keep running](/learn-v2/agent/managing-chats) while you work elsewhere.
