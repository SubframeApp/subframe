Agent chat lets you use Claude Code, Codex, or models powered by Subframe AI credits in the same workspace as your designs and running app.

## Working across designs, browser, and code

Use the agent to:

- Create or edit designs in Subframe
- Turn browser edits and comments into code changes
- Implement a design in your connected codebase
- Start your local development server

The agent automatically receives context from the view you're working in. You can also [add more context](/learn-v2/agent/giving-your-agent-context) by referencing project content, pasting designs, or attaching images.

To make changes to local code, first [connect your codebase](/learn-v2/agent/connecting-your-codebase).

## Opening Agent chat

Click **Agent** in the desktop title bar or press <kbd>Cmd</kbd> + <kbd>/</kbd>.

Agent chat stays open as you move between designs and browser tabs.
