  <Accordion title="How is the desktop app different from the web app?">
    Both share the same canvas, projects, and designs. With the desktop app, you can also:

    1. **Connect to your local codebase.** Subframe detects dev servers running on localhost and designs with the components from your code.
    2. **Use the built-in browser.** Features like Inspect, Capture, and live edits on your running app are desktop-only.
    3. **Connect to your own coding agents.** If you don't want to use Subframe's built-in AI, use your own Claude Code or Codex subscription instead.
  </Accordion>
