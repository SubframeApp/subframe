Subframe is a design tool for your codebase. It brings the three tools you use to make software together in one place:

- **[Canvas](/design/overview)**: design on an infinite canvas using HTML, CSS, React, and Tailwind
- **[Browser](/browser/overview)**: preview your live app, edit it visually, and capture it as a design
- **[Agent](/agent/overview)**: work with Claude Code, Codex, or Subframe AI credits across your designs, browser, and code

<Note>
  Use the [desktop app](/desktop-app) to work with your local codebase, development server, and coding agent. Download
  it for macOS at [subframe.com/downloads ↗](https://subframe.com/downloads).
</Note>

## How Subframe works

Subframe lets you go from design to code and back. Here's a typical workflow:

<Steps>
  <Step title="Open your app">[Open your local app](/browser/previewing-your-local-app) in the built-in browser.</Step>
  <Step title="Edit it live">[Use **Inspect**](/browser/making-live-edits) to change the running page visually.</Step>
  <Step title="Design on the canvas">
    [Capture the page or an element](/browser/capturing-as-designs) as an editable design and explore bigger changes on
    the canvas.
  </Step>
  <Step title="Ship with the agent">
    [Ask the agent to implement your design](/agent/making-code-changes) in your connected codebase.
  </Step>
</Steps>

Ready to try it? Start with the [Quickstart](/quickstart).
