The [desktop app](/desktop-app) includes a browser for working with your running app next to your designs and [Agent chat](/agent/overview).

Each browser tab has three modes:

- **[Preview](/browser/previewing-your-local-app)**: interact with the page like in any browser
- **[Inspect](/browser/making-live-edits#editing-the-live-page)**: select elements and edit them visually
- **[Annotate](/browser/making-live-edits#adding-a-comment)**: add implementation notes or images for your agent

[Capture the full page](/browser/capturing-as-designs) to copy it to the canvas as an editable design.
