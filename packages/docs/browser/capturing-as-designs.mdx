[Open your app or website in a browser tab](/browser/previewing-your-local-app). A capture recreates the rendered page as editable Subframe elements. It does not import the original React components, application logic, or a live connection to the source files.

## Capturing a page

1. Click **Capture** in the browser toolbar
2. Add the page to a canvas:
   - Click **Add to canvas** in the confirmation message. If a canvas is already selected, the button names it; use the dropdown to choose another
   - Or open a canvas and press <kbd>Cmd</kbd> + <kbd>V</kbd> to paste it

## Capturing an element

Capture an element when you only need part of the page.

1. Click **Inspect** in the browser toolbar
2. Click on an element
3. Press <kbd>Cmd</kbd> + <kbd>C</kbd> or click **Copy selection** on the selected element's card
4. Paste the element onto a canvas or into [Agent chat](/agent/giving-your-agent-context#pasting-designs-and-browser-captures)
