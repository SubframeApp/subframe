---
title: Managing chats
description: Start, revisit, and track agent work across your project.
---

Each [Agent chat](/agent/overview) keeps its own conversation and can continue running while you work elsewhere.

## Starting a new chat

Click **New chat** at the top of Agent chat. Start a new chat when you move to a separate task or no longer need the context from the current conversation.

## Returning to a past chat

1. Click the chat name at the top of Agent chat
2. Select a conversation from the history

Chat history is grouped by when you last used each conversation.

## Tracking active and unread chats

An animated indicator marks a chat that is still running. A dot marks a completed response you haven't opened.

You can switch chats or close Agent chat without stopping work in progress.

## Getting notified when the agent responds

When Subframe asks for permission to send notifications, click **Allow**.
