---
title: Giving your agent context
description: Point the agent to the designs, browser pages, project content, images, and files it needs.
---

Good context tells [Agent chat](/agent/overview) what you're referring to and where the result should go.

## Using your current view

Agent chat automatically includes the view you're working in when you send a message. This can be a design, selected page on a canvas, [browser tab](/browser/overview), theme, component library, snippets, icons, or project documentation.

If you select elements in a design, the agent knows which ones you mean. Select a button and ask it to "make this bigger" to change only that button.

The badge above the chat box shows the most specific context that will be sent with your next message, like the selected element or page.

## Referencing pages, components, and snippets with @

Use an @ reference when the agent needs something outside your current view.

1. Type <kbd>@</kbd> in the chat box
2. Select a page, component, or snippet
3. Write your request and send it

## Sharing product context and design guidelines

Use [design docs](/design/documents) to give the agent product context, brand voice, and design rules. Keep guidance that applies throughout your project in the doc marked **Always read by the agent**. The agent uses doc titles to find and read other docs as needed for your task.

## Pasting designs and browser captures

1. Copy a design, selected element, or [browser capture](/browser/capturing-as-designs)
2. Paste it into Agent chat
3. Add instructions and send your message

## Continuing a conversation from another agent

Bring work you started in Claude, Codex, Cursor, or Conductor into Agent chat so you don't have to explain it again.

1. In a new chat, click **Continue conversation from another agent…**
2. Select the app you're coming from and follow its steps to copy the conversation
3. Paste it into Agent chat, then add what you want to do next and send

In Claude Code or the Codex CLI, run `/export` and choose **Copy to clipboard**. In the Claude web or desktop app, click **Copy prompt**, send it in your Claude conversation, and paste the summary it writes.

A paste longer than 20 lines or 1,000 characters is added as an attachment instead of text in the chat box. This applies to any long text you paste, such as logs or specs.

## Adding images and files

Click the <Icon icon="paperclip" size={16} /> **Attach images or files** button, drag files into the chat box, or paste them from your clipboard. Add a message explaining what the agent should use from them, then send it.

You can attach any file type, like a spec, a CSV, a PDF, or source code, up to 30 MB each. The agent opens each file with its own tools and tells you if it can't read one.

## Sending browser edits and comments

After [editing or commenting on your live app](/browser/making-live-edits), click **Send** in the browser toolbar. Subframe sends the changes, comments, and a screenshot to Agent chat.

To include more instructions, open Agent chat before sending your message. Your pending browser changes are attached automatically.
