Comments let you leave feedback directly on your designs. Adding and viewing comments is available on all plans (including viewers). You can only add comments to pages today.

## Adding comments

<Frame>
  <img src="/images/design-mode/add-comment.png" alt="Add comment button showing the comment input" />
</Frame>

1. Click **Comment** in the toolbar, or press <kbd>C</kbd>
2. Click on an element to add a comment

Comments stay attached to specific elements. When you move or edit an element, its comments move with it. Comments are shown as pins directly on the design or in the right side panel.

## Reviewing comments across a flow

You can leave and read comments without opening a page. Enter Comment mode from a [flow](/learn/flows/flows) to work across the whole canvas:

1. Open a flow, then click **Comment** in the toolbar or press <kbd>C</kbd>
2. Comment pins appear on the page previews on the canvas
3. The **Comments** panel on the right lists every thread grouped by page—click a thread to jump to it

Add new comments the same way as on a page: click an element in a preview to start a thread.

## Moving comments

1. Select a comment thread pin
2. Drag the pin to reposition it within the design

## Mentioning teammates

1. Type <kbd>@</kbd> in a comment
2. Select a user to mention

Mentioned users will receive an email notification.

## Resolving comments

1. Open the comment thread
2. Click the checkmark <Icon icon="circle-check" size={16} /> to resolve
