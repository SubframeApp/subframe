The desktop and web apps share the same canvas, projects, and designs. Use the desktop app to connect Subframe to the code and development tools on your computer.

## Working locally with the desktop app

The desktop app gives you access to workflows that are not available in the web app:

1. **[Connect your codebase](/agent/connecting-your-codebase).** Select a local repository so the agent can read and edit its files.
2. **[Use your own coding agent](/agent/connecting-an-agent).** Connect your Claude Code or Codex subscription to Agent chat.
3. **[Make changes in code](/agent/making-code-changes).** Ask your agent to update your connected codebase and review the result in your running app.
4. **[Edit your local app](/browser/making-live-edits).** Make visual changes in the built-in browser and send them to your agent.

## Working with tabs

Use tabs to keep designs, local apps, and websites open in the same workspace.

- Press <kbd>Cmd</kbd> + <kbd>T</kbd> to open a new tab
- Press <kbd>Cmd</kbd> + <kbd>W</kbd> to close the current tab
- Click a tab in the title bar to switch to it

From a new tab, you can [connect your codebase and open your local app](/browser/previewing-your-local-app). Under **Recent**, click a design or website you viewed recently to reopen it.

## Working with windows

Open more windows to work on several projects side by side. Each window has its own project, tabs, and Agent chat.

- Press <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd>, or click the **project menu** <Icon icon="chevron-down" size={16} /> next to the Subframe logo and select **New window**
- Press <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> to close the current window
- Shift-click a project on the **Projects** page to open it in its own window

A link to another project opens in the window that already shows that project. Windows you leave open come back with their tabs the next time you start the app.

## Opening links in the desktop app

Once you've set up the desktop app, a project link you open in your web browser opens in the desktop app. To keep working in the browser, click **Open in browser instead**.

To move a project you have open in the browser to the desktop app, click the **project menu** <Icon icon="chevron-down" size={16} /> and select **Open in desktop app**.

## Supported platforms

The desktop app is available for macOS (Apple Silicon and Intel) and Windows (64-bit). Download it at [subframe.com/downloads ↗](https://subframe.com/downloads).

On Windows, press <kbd>Ctrl</kbd> wherever these docs say <kbd>Cmd</kbd>.

Linux support is coming soon.
