Subframe's code exporter translates the design's elements, layout, styles, props, and variants into code. This export is deterministic: the same design and export settings produce the same code. AI can create or edit the design, but the exporter does not ask an LLM to interpret it.

## Editing a design and inspecting its code

The **Code** tab updates as you edit a design. You are changing Subframe's design model; your application's source files change only when you copy code, run the CLI, or have an agent implement the design.

Generated code handles presentation and component interactions. Add API calls, routing, authentication, and product-specific state in your application.

## Using Tailwind CSS

Subframe exports layout and styling as Tailwind utilities and generates a theme from your design tokens. It supports Tailwind v3 and v4; the CLI records your choice in `.subframe/sync.json`.

Use the [Tailwind v3](https://v3.tailwindcss.com/docs) or [Tailwind v4](https://tailwindcss.com/docs) documentation for configuration and utility reference.

## Headless components

Interactive components use [`@subframe/core`](https://github.com/SubframeApp/subframe/tree/main/packages/subframe-core), which includes headless primitives such as Radix. These supply behavior such as opening a dropdown, managing focus in a dialog, and keyboard navigation while your design supplies the styles.

Component interaction state is part of this behavior. Your application still controls product state, such as the selected account or data returned from an API. Use [props, slots, and wrappers](/develop/concepts/syncing-components#adding-business-logic) to connect the two.

Headless primitives help with accessibility, but your interface still needs appropriate labels, semantics, and contrast. See [Accessibility](/develop/guides/accessibility).

## Implementing with an agent

[Agent chat](/agent/making-code-changes) and the [MCP server](/agent/mcp-server) let an agent read the design and implement it in your codebase. The agent's implementation is a separate step from deterministic code export. Give it the target page, existing components to reuse, and behavior to preserve, then review the result in your app.
