Use this workflow when you want Subframe to manage your component library's visual design. You edit components in Subframe, sync their React code into your app, and add application logic in code.

If you're working on an existing app, start with the [desktop quickstart](/quickstart). You can capture screens, explore designs, and ask the agent to implement changes using your existing code. You don't need to replace your component library to use that workflow.

## Setting up your design system

1. **Define your theme.** Create or import [colors, typography, and other design tokens](/design/theme/customizing-theme).
2. **Build your components.** Create [buttons, inputs, cards, and other reusable elements](/design/components/overview).
3. **Install Subframe.** Run the [CLI setup](/develop/installation) and choose a directory for the generated UI files.
4. **Sync your library.** Run `npx @subframe/cli@latest sync --all` after design changes.
5. **Add application logic.** Use component props, slots, and [wrappers](/develop/concepts/syncing-components#wrapping-components) for handlers and product behavior.

## Building pages with your components

Design pages from your component library, then implement them with [Agent chat](/agent/making-code-changes), an [external agent](/agent/mcp-server), or copied React code. Pages become application code that you maintain; the CLI continues to manage the reusable components separately.

See the [design-to-code workflow](/develop/concepts/design-to-code) for an example.
