## Enabling dark mode in Subframe

1. Open **Theme** in the left sidebar
2. Click **⋯** and select **Add dark mode**
3. Edit the light and dark values for your tokens
4. Preview designs with the sun/moon control in the editor toolbar

To remove dark values, open the same menu and select **Remove dark mode**. Restore an earlier theme through [version history](/design/projects/version-history#theme-version-history) if needed.

## Syncing and loading the theme

Run the CLI from your project root:

```bash
npx @subframe/cli@latest sync --all
```

The output depends on `cssType` in `.subframe/sync.json`:

- **Tailwind v3:** the generated `tailwind.config.js` references CSS variables and configures class-based dark mode. `theme.css` contains the light values and dark overrides.
- **Tailwind v4:** `theme.css` contains the theme values, dark overrides, and dark variant.

Import the generated stylesheet in your global CSS. Adjust the path for your sync directory:

```css src/styles.css
@import "./ui/theme.css";
```

For Tailwind v4, keep `@import "tailwindcss";` before the theme import. See [manual setup](/develop/frameworks/manual#loading-the-theme) for both versions.

## Switching modes in your app

The `dark` class on the `<html>` element activates dark values. Your app controls that class and the user's preference.

For Next.js, [next-themes](https://github.com/pacocoursey/next-themes#readme) handles system preference and persistence:

```bash
npm install next-themes
```

```tsx app/layout.tsx
import type { ReactNode } from "react"
import { ThemeProvider } from "next-themes"

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  )
}
```

Wait until the client has mounted before displaying a theme-dependent toggle. Use `resolvedTheme` so the toggle also works when the saved preference is `system`:

```tsx app/ThemeToggle.tsx
"use client"

import { useEffect, useState } from "react"
import { useTheme } from "next-themes"

export function ThemeToggle() {
  const [mounted, setMounted] = useState(false)
  const { resolvedTheme, setTheme } = useTheme()

  useEffect(() => setMounted(true), [])

  if (!mounted) return null

  const isDark = resolvedTheme === "dark"
  return (
    <button type="button" onClick={() => setTheme(isDark ? "light" : "dark")}>
      Use {isDark ? "light" : "dark"} mode
    </button>
  )
}
```

Check text contrast, borders, and interactive states in both modes after integrating the theme.
