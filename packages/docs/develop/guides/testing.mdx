---
title: Testing
description: Add test attributes to Subframe components.
---

Components pass through props to their root element. For a test that fills a text field, put `data-testid` on `TextField.Input` so it identifies the input rather than the surrounding label:

```tsx EmailField.tsx
import { TextField } from "@/ui/components/TextField"

export function EmailField() {
  return (
    <TextField label="Email">
      <TextField.Input name="email" type="email" data-testid="email-input" />
    </TextField>
  )
}
```

For reusable test IDs, add them in the component's [wrapper `index.tsx`](/develop/concepts/syncing-components#wrapping-components) so they're included by default.
