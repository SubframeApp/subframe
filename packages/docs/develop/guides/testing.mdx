Prefer tests that find controls by their role and accessible name. When you need a test ID, add it to the element the test should interact with.

## Adding test attributes

Props on a generated component reach its root element. For nested controls, add the attribute to the subcomponent:

```tsx EmailField.tsx
import { TextField } from "@/ui/components/TextField"

export function EmailField() {
  return (
    <TextField label="Email">
      <TextField.Input name="email" type="email" data-testid="email-input" />
    </TextField>
  )
}
```

Putting `data-testid` on `TextField` would identify the wrapper; putting it on `TextField.Input` identifies the input you can fill.

Keep reusable test attributes in a [sync-protected wrapper](/develop/concepts/syncing-components#wrapping-components) when they should survive future syncs.
