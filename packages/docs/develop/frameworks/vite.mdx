Start with a [React Vite app](https://vite.dev/guide/#scaffolding-your-first-vite-project) and [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite).

## Installing Subframe

Run the CLI from your app's root and follow the prompts:

```bash
npx @subframe/cli@latest init
```

## Configuring import aliases

For a sync directory of `src/ui`, add this alias to the TypeScript config used by your app, usually `tsconfig.app.json`. Merge it into the existing `compilerOptions`:

```json tsconfig.app.json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Configure the same alias in Vite. Install Node's types if they are not already present:

```bash
npm install -D @types/node
```

Merge `resolve.alias` into your existing Vite config, keeping your current plugins and other options. A React configuration looks like this:

```ts vite.config.ts
import { fileURLToPath, URL } from "node:url"
import { defineConfig } from "vite"
import react from "@vitejs/plugin-react"

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      "@": fileURLToPath(new URL("./src", import.meta.url)),
    },
  },
})
```

Adjust both paths if you chose a different source directory. For other configuration issues, follow [manual installation](/develop/frameworks/manual).
