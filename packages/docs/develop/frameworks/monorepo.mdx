This example uses a shared package at `packages/subframe` and a Next.js app at `apps/web`. Set up React and Tailwind in the app first. The same package structure works with other frameworks that can compile shared React source.

## Creating a shared package

Create `packages/subframe` and include it in your package manager's workspaces. Start with this `package.json`:

```json packages/subframe/package.json
{
  "name": "@repo/subframe",
  "version": "0.0.0",
  "private": true
}
```

Add a TypeScript configuration for React. You can extend your monorepo's existing React configuration or use:

```json packages/subframe/tsconfig.json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "jsx": "react-jsx",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "noEmit": true
  },
  "include": ["ui"]
}
```

Use the same React version as the consuming apps, and make React's type definitions available to this package.

## Installing Subframe

Run the CLI inside the shared package:

```bash
cd packages/subframe
npx @subframe/cli@latest init --sync --dir ui --alias '@repo/subframe/*' --no-tailwind
```

Select your Subframe project and the Tailwind version used by your apps. Confirm the import alias update when prompted. The CLI syncs into `packages/subframe/ui` and installs `@subframe/core`; the consuming apps load the theme in the steps below.

<Note>
  The import alias also changes code copied from your Subframe project. Use `@repo/subframe/*` in the local CLI
  settings; the project's code export setting uses `@repo/subframe` without the wildcard.
</Note>

## Exporting components from the package

Add these exports to `package.json`, preserving the dependencies installed by the CLI. Include `tailwind-config` for v3 and `theme.css` when that file is generated:

```json packages/subframe/package.json
{
  "name": "@repo/subframe",
  "version": "0.0.0",
  "private": true,
  "exports": {
    "./components/*": "./ui/components/*/index.tsx",
    "./layouts/*": "./ui/layouts/*/index.tsx",
    "./icons/*": "./ui/icons/*.tsx",
    "./utils": "./ui/utils.ts",
    "./theme.css": "./ui/theme.css",
    "./tailwind-config": "./ui/tailwind.config.js"
  }
}
```

Components and layouts sync as [directories](/develop/upgrading/component-directories). Their exports point to the `index.tsx` wrapper inside each directory. There is no generated `ui/index.ts` barrel.

## Linking the package to your app

Add `@repo/subframe` to the consuming app's `dependencies`. Use `"*"` with npm, or `"workspace:*"` with pnpm, Bun, or modern Yarn. Run your package manager's install command from the repository root.

This package exports TypeScript source. Configure the app's bundler to compile it. For Next.js, merge [transpilePackages](https://nextjs.org/docs/app/api-reference/config/next-config-js/transpilePackages) into your existing configuration:

```javascript apps/web/next.config.mjs
export default {
  transpilePackages: ["@repo/subframe"],
}
```

## Loading the theme in your app

<Tabs>
  <Tab title="Tailwind v3">
    Add the package's preset and component source path to the app's existing Tailwind configuration:

```javascript apps/web/tailwind.config.js
import subframePreset from "@repo/subframe/tailwind-config"

export default {
  content: ["./{app,pages,components,src}/**/*.{js,ts,jsx,tsx}", "../../packages/subframe/ui/**/*.{js,ts,jsx,tsx}"],
  presets: [subframePreset],
}
```

    If your theme has dark mode, also import `@repo/subframe/theme.css` in the app's global stylesheet, before the Tailwind directives.

  </Tab>
  <Tab title="Tailwind v4">
    Import the theme and register the shared component files for [class detection](https://tailwindcss.com/docs/detecting-classes-in-source-files#explicitly-registering-sources):

```css apps/web/app/globals.css
@import "tailwindcss";
@import "@repo/subframe/theme.css";
@source "../../../packages/subframe/ui";
```

    The `@source` path is relative to this stylesheet. Adjust it if your CSS file lives elsewhere.

  </Tab>
</Tabs>

Install any [custom fonts](/design/theme/adding-custom-fonts#installing-fonts-in-your-codebase) in each consuming app.

## Using and updating the shared components

Import components through the package:

```tsx
import { Button } from "@repo/subframe/components/Button"
```

After design changes, run sync from `packages/subframe`:

```bash
npx @subframe/cli@latest sync --all
```

Each app uses the updated shared files. Follow the [sync customization rules](/develop/concepts/syncing-components) when adding wrappers or editing generated code.
