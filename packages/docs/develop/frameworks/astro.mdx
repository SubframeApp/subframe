Start with an Astro app configured for [React](https://docs.astro.build/en/guides/integrations-guide/react/) and [Tailwind CSS](https://docs.astro.build/en/guides/styling/#tailwind). Subframe's generated components use React.

## Installing Subframe

Run the CLI from your app's root and follow the prompts:

```bash
npx @subframe/cli@latest init
```

## Configuring import aliases

For components under `src/ui`, merge the following settings into your existing `tsconfig.json`. Keep any other aliases and compiler options your project uses:

```json tsconfig.json
{
  "extends": "astro/tsconfigs/strict",
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react",
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": [".astro/types.d.ts", "**/*"],
  "exclude": ["dist"]
}
```

Astro uses these aliases when resolving imports. Adjust the path if you chose a different sync directory.

## Enabling client interactions

Hydrate a React component with an Astro [client directive](https://docs.astro.build/en/reference/directives-reference/#client-directives) when it needs event handlers or interactive primitives. Put the interactive UI in a React component, then render that component from your Astro page:

```tsx src/components/Counter.tsx
import { useState } from "react"
import { Button } from "@/ui/components/Button"

export function Counter() {
  const [count, setCount] = useState(0)
  return <Button onClick={() => setCount(count + 1)}>Count: {count}</Button>
}
```

```astro src/pages/index.astro
---
import { Counter } from "../components/Counter"
---

<Counter client:load />
```

For configuration issues, follow [manual installation](/develop/frameworks/manual).
