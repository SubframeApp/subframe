Use `npx @subframe/cli@latest init` for automatic setup. Follow these steps to configure an existing React, TypeScript, and Tailwind app yourself. The examples use `src/ui` as the directory managed by Subframe.

## Configuring the CLI

Create `.subframe/sync.json` in your project root:

```json .subframe/sync.json
{
  "directory": "./src/ui",
  "importAlias": "@/ui/*",
  "projectId": "YOUR_PROJECT_ID",
  "cssType": "tailwind-v4"
}
```

- **`directory`:** where generated UI files are written.
- **`importAlias`:** the import prefix mapped to that directory.
- **`projectId`:** your Subframe project ID, shown on the [CLI auth page](https://app.subframe.com/cli/auth).
- **`cssType`:** `tailwind-v4` for Tailwind v4 or `tailwind` for Tailwind v3.

The sync directory should contain generated UI files and explicitly [sync-protected files](/develop/concepts/syncing-components#disabling-sync). A full sync removes other unprotected contents.

## Installing and syncing components

Install the component runtime, then sync:

```bash
npm install @subframe/core@latest
npx @subframe/cli@latest sync --all
```

Follow the authentication prompt, or provide a token as described in [CLI automation](/develop/guides/cli-automation).

## Resolving component imports

Merge the following alias into your TypeScript configuration:

```json tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@/ui/*": ["./src/ui/*"]
    }
  }
}
```

Your framework or bundler must resolve the same alias. Next.js and Astro read TypeScript path aliases; [Vite requires matching configuration](/develop/frameworks/vite#configuring-import-aliases).

In Subframe's [code export settings](/design/projects/project-settings), set **Import alias** to `@/ui` so copied code uses the same prefix.

## Loading the theme

<Tabs>
  <Tab title="Tailwind v3">
    Add the generated config as a preset and include your UI files in `content`. Merge this with your existing config:

    ```js tailwind.config.js
    module.exports = {
      content: ["./index.html", "./src/**/*.{js,jsx,ts,tsx}"],
      presets: [require("./src/ui/tailwind.config")],
    }
    ```

    If your theme has dark-mode values, also import the generated `theme.css` in your global CSS:

    ```css src/styles.css
    @import "./ui/theme.css";

    @tailwind base;
    @tailwind components;
    @tailwind utilities;
    ```

  </Tab>
  <Tab title="Tailwind v4">
    Import the generated theme after Tailwind in your global stylesheet:

    ```css src/styles.css
    @import "tailwindcss";
    @import "./ui/theme.css";
    ```

    If your UI directory is outside Tailwind's detected sources, add an [`@source` directive](https://tailwindcss.com/docs/detecting-classes-in-source-files). See the [monorepo guide](/develop/frameworks/monorepo).

  </Tab>
</Tabs>

Make sure your app loads this global stylesheet. After changing tokens in Subframe, run sync again to update the generated theme.

## Loading fonts

Load the Google Fonts or custom font files used by your theme. Follow [Installing fonts](/develop/installation#install-fonts); syncing tokens does not install custom font files.
