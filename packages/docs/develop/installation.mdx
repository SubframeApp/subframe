## Prerequisites

Subframe generates React components with Tailwind CSS. Your project needs:

- React 16.8 or later, with a compatible React DOM version
- Tailwind CSS 3.4 or 4
- TypeScript

## Install Subframe

Start from a new project or install in an existing project. Our CLI is [open source ↗](https://github.com/SubframeApp/subframe/tree/main/packages/subframe-cli) and will help you get started quickly.

## Install fonts

Load the fonts used by your theme in your app. Syncing typography tokens alone does not install fonts.

### Google Fonts

1. Open **Theme → Typography** in Subframe
2. Click **Installation** and copy the Google Fonts import snippet
3. Add it to your app's HTML `<head>`, or load the same families and weights with your framework's font loader

### Custom fonts

1. Copy your licensed font files into your app's public assets, such as `public/fonts/`
2. Add `@font-face` declarations to your global CSS, matching the family names, weights, and styles used in Subframe

For a variable font whose metadata supports weights 100–900:

```css src/styles.css
@font-face {
  font-family: "Acme Sans";
  src: url("/fonts/acme-sans.woff2") format("woff2");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}
```

Replace the name and path with your font. For static fonts, declare each file's weight and style separately. The CLI does not download uploaded custom font files.

## FAQ

<AccordionGroup>
  <Accordion title="What if I don't use React, TypeScript or Tailwind CSS?">
    You can use our [MCP server](/agent/mcp-server) to access your designs and documentation in your AI coding assistant and convert them to your preferred language and framework.

    The generated component code targets React, TypeScript, and Tailwind. An agent can use the design as a reference for another stack, but you need to review and test that implementation separately.

  </Accordion>
  <Accordion title="Will my code keep working if I stop using Subframe?">
    Yes. All generated code lives in your codebase and is yours to keep. Any dependencies you see are [open source ↗](https://github.com/SubframeApp/subframe).
