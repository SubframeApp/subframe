# Subframe

Design UI for your codebase. The Subframe plugin connects Antigravity’s agent to Subframe, a visual design tool built on HTML and CSS.

## What you can do

- Design pages, components, and snippets.
- Find inspiration in real websites and explore variations of a screen.
- Manage your theme and tokens, and write design documents.
- Read designs and their React and Tailwind code for implementation.
- Export designs as images or PDFs.

## Get started

Install the Subframe plugin from Antigravity’s Marketplace. Your first Subframe tool call opens Subframe sign-in in your browser.

Try a suggested prompt:

- Design a landing page for a neighborhood bakery, using real landing pages for inspiration.
- Create three variations of a personal finance dashboard with distinct layouts.
- Design an event page with a speaker lineup, schedule, and a bold orange theme.
