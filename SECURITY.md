# Security policy

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/SubframeApp/subframe/security/advisories/new) ("Report a vulnerability" on the Security tab). Please don't open a public issue.

We'll acknowledge your report and keep you updated until it's resolved. This policy covers the code in this repository: `@subframe/cli`, `@subframe/core`, the plugin and skills, and the starter kits.
